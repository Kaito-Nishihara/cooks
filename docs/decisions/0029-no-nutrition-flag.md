# 0029 栄養の値がない食材に、印を付ける

決めた日: 2026-10-11

## 状況

要件定義 4.3 は、成分表の食品番号が設定されていない食材を、栄養計算から除き、除いた材料があるレシピを「概算値」と表示すると決めている。
水は、親子丼の割下のように、今の 38 品の材料に出てくるが、取得した成分表のファイルを「水道」「飲料水」「ミネラルウォーター」で探しても、食品として見つからなかった。
そのままでは、水に食品番号を付けられず、水を使うレシピがすべて「概算値」になる。

## 決めたこと

食材マスタに `noNutrition`(真偽値)を足し、これが `true` の食材は、栄養計算から除かずに、すべての値を 0 として計算に入れる。

## 理由

- 「値が分からないから除く」と「値が 0 だと分かっている」を、区別して持てる。
- 「概算値」の印が、本当に値が抜けているレシピにだけ付く。
- 水は換算率を書かなくても計算に入るので、`ml` でも `カップ` でも「概算値」にならない。

## 却下した案

- **水に、成分がほぼ 0 の別の食品の番号を付ける**: 項目を足さずに済む。別の食品を指すことになり、食材マスタを読んだ人が誤解する。
- **`data/foods.json` に、成分表にない「水」の行を手で足す**: 食材マスタの形が変わらない。`data/foods.json` は変換スクリプトが作るファイルで、手で足した行は、次の変換で消える。成分表にない番号を作ることにもなる。
- **画面のコードで、水だけを特別に扱う**: データの項目が要らない。どの食材が特別なのかが、コードを読まないと分からない。

## 影響

- 要件定義 7.2 の食材マスタの項目に、`noNutrition` を足す。
- `foodNumber` と `noNutrition` は、同時に書けない。`check:data` が確かめる。
- 今、この印を付けるのは水だけである。ほかの食材に付けるときは、成分表に当てはまる食品がないことを確かめ、PR の本文に書く。
- 成分表の探し方が足りず、水に当たる食品が見つかったときは、その食品番号を付けて、この印を外す。
