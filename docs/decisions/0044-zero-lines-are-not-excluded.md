# 0044 寄与が 0 と決まっている材料は、g に直せなくても計算から除かない

決めた日: 2026-10-11

## 状況

要件定義の 4.3 は、単位から g への換算率がない材料と、食材マスタにない材料を、栄養計算から除くと決めている。
除いた材料が 1 つでもあると、結果は「概算値」になる。
一方で、水(食材マスタの `noNutrition`)は、除かずに 0 として計算に入れるとも決めている。
また、データ設計は、香り付けだけで取り出す材料(ローリエなど)に、摂取する割合(`intakeRatio`)の 0 を付けると決めている。
水が ml で書かれていて換算率がないときや、ローリエが食材マスタにないときに、どちらの決まりを先に当てるかを決める必要があった。
あわせて、「計算できた材料が一つもないときは未算出」の、「計算できた材料」が何を指すかも決める必要があった。

## 決めたこと

摂取する割合が 0 の行と、`noNutrition` の食材の行は、g に直せるかどうかを見ずに、寄与を 0 として計算に入れる。
ただし、未算出かどうかを決める「計算できた行」には数えない。

## 理由

- 寄与が 0 と決まっている行は、何 g であっても合計を変えない。g に直せないことを理由に「概算値」にすると、印が、値に関わりのない場面で付く。印が多すぎると、調味料が抜けているような、気を付けるべき場面と区別できなくなる(決定の記録 0028 と同じ考え方である)。
- 水に、`ml`、`カップ`、`大さじ` の換算率を書かせなくて済む。
- 寄与が 0 の行だけのレシピに数を出すと、「0kcal」と出る。水と「適量」の薬味だけのレシピが「0kcal(概算値)」と出ると、実際に 0kcal であるかのように見える。成分表の値を 1 つも使っていないときは、数を出さないほうが誤解がない。

## 却下した案

- **換算の判定を先にする**: 判定の順が、要件定義の箇条書きの順と同じになる。水を ml で使うレシピが、水に換算率を書くまで、すべて「概算値」になる。
- **摂取する割合が 0 の行を、除いた材料として出す**: 食べない材料があることを、一覧で見られる。「計算から除いた」のではなく「食べない」材料であり、概算であることの理由にならない。
- **寄与が 0 の行も、「計算できた行」に数える**: 決まりが 1 つ減る。水だけが計算できたレシピに「0kcal」と出る。

## 影響

- 行の判定は、分量、摂取する割合、食材マスタ、`noNutrition`、食品番号、換算率の順になる。順は、機能設計「栄養計算」の 5.5 に書いた。
- 材料が水だけのレシピは、実際に 0kcal だが、「栄養値は未算出」と出る。今の 38 品に、そのようなレシピはない。
- 要件定義の 4.3 に、この 2 点を足した。
- `noNutrition` を水のほかの食材に付けるようになり、0 でない値を持つものが混ざったときは、この決定を見直す。
