# 0061 ログインしていない人にも、献立と編集の入口を出す

決めた日: 2026-10-11

## 状況

献立と編集には、ログインが要る。
画面の一覧と遷移の 3.4 は、ログインしていない人に「今日の献立」「献立に追加」「編集する」を出さない、としていた。
今の静的なレシピ集は、誰でも献立を使える。
入口を隠すと、移行の後に、機能が減ったように見える。

## 決めたこと

ログインしていない人にも「今日の献立」「献立に追加」「編集する」を出し、押したらログインの画面へ移す。

## 理由

- ログインの前に、どんな機能があるかが分かる。
- 今のレシピ集を使っている人が、献立の入口を見失わない。
- 利用者が選んだ(2026-10-11)。
- 「今日の献立」と「編集する」は、ふつうのリンクのままでよい。ログインが要る画面を包む枠が、すでにログインの画面へ移す。足す処理は、「献立に追加」を押したときの移動だけである。

## 却下した案

- **出さない**: 画面が単純で、押しても使えない入口がない。機能があることが、ログインするまで分からない。
- **ログインして戻った後に、押した操作(料理を足す)を自動で行う**: 押し直しが要らない。ログインした人の役割が見るだけのことがあり、戻った先で開いているレシピ帳も、押したときには決まっていない。どのレシピ帳に足すかを、利用者が選んでいないまま保存することになる。
- **見るだけの人にも出し、押したら「権限がありません」と知らせる**: 出し分けの条件が減る。ログインしても使えない入口を、押せる形で見せることになる。

## 影響

- ログインしていない人のヘッダーに、「今日の献立」が増える。
- レシピ一覧のすべてのカードと、レシピ詳細に、ログインしていない人にもボタンが出る。
- 入口を出すことは、権限の判定に関わらない。API は、今までどおり 401 を返す。
- 見るだけの人には、今までどおり「献立に追加」と「編集する」を出さない。
