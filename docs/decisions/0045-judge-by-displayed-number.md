# 0045 範囲や目安に収まるかどうかを、画面に出る数で判定する

決めた日: 2026-10-11

## 状況

今日の献立では、たんぱく質、脂質、炭水化物がエネルギーに占める割合を、目標の範囲(例: たんぱく質は 13〜20%)と並べて出す。
食塩相当量は、1 日の目安(例: 男性は 7.5g 未満)と並べて出す。
画面には丸めた数を出すので、範囲に収まるかどうかを、丸める前の数で判定するか、丸めた後の数で判定するかを決める必要があった。
今の静的レシピ集は、丸める前の数で判定している。

## 決めたこと

範囲や目安に収まるかどうかは、画面に出る数(丸めた後の数)で判定する。

## 理由

- 利用者が見るのは、丸めた後の数と、範囲の端の数である。丸める前の数で判定すると、「20%(目標 13〜20%)」が範囲の外と出ることがある。例: 検証用のデータで計算した親子丼のたんぱく質は 20.28% で、表示は「20%」である。
- 栄養の値そのものが概算で、換算率や摂取する割合の見込みを含む。1% に満たない差で、範囲の内と外を分ける意味がない。

## 却下した案

- **丸める前の数で判定する(今の静的レシピ集と同じ)**: 計算としては正確である。画面の数と判定が食い違って見える場面がある。
- **割合を小数 1 桁で出して、その数で判定する**: 食い違って見える場面が減る。もとの値の確かさに比べて、細かすぎる桁を見せることになる。

## 影響

- エネルギーに占める割合は、整数に四捨五入した後の数が、範囲の下の端以上、上の端以下なら、範囲の中とする。
- 食塩相当量は、小数 1 桁に四捨五入した後の数が、目安より小さければ、目安の中とする。
- 合計そのもの(5 つの成分の値)は、丸める前の値で足す(決定の記録 0043)。この決定が当たるのは、範囲や目安との比べだけである。
