# 画面: レシピ帳の設定

今開いているレシピ帳の名前、メンバー、招待を扱う画面である。

| 項目 | 内容 |
|---|---|
| パス | `/book` |
| ログイン | 要る。メンバーの全員。変えられるのは持ち主 |
| 骨組みと遷移 | [画面設計: 画面の一覧と遷移](../design/screens.md) の 3.3 と 3.8 |

## 対応する機能設計

| 文書 | この画面について決めていること |

幅 1,100px のブラウザでの表示である。
枠の中は、押したりスクロールしたりできる。保存はされない。
