# 画面: 今日の献立

その日の朝食、昼食、夕食の料理とご飯を並べ、栄養の合計を出す画面である。

| 項目 | 内容 |
|---|---|
| パス | `/menu`、`/menu?day=<日付>` |
| ログイン | 要る。メンバーの全員。変えられるのは、編集できる人と持ち主 |
| 骨組みと遷移 | [画面設計: 画面の一覧と遷移](../design/screens.md) の 3.3 と 3.8 |

## 対応する機能設計

| 文書 | この画面について決めていること |
|---|---|
| [機能設計: 今日の献立](../design/menu.md) | 料理を足す入口、食事を移す、外す、ご飯の杯数、日付の移動、自動保存 |
| [機能設計: 栄養計算](../design/nutrition.md) | 食事ごとの小計、1 日の合計、割合、目安との比べ |

## 見た目の試作

幅 1,100px のブラウザでの表示である。
枠の中は、押したりスクロールしたりできる。保存はされない。

### 持ち主。朝食と夕食に料理がある状態

広いときは、食事を左、1 日の合計を右に置く。
