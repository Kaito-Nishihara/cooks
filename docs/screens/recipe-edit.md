# 画面: レシピの編集

レシピ帳ごとに、レシピの材料、手順、コツ、メモを直す画面である。保存のボタンはなく、自動で保存する。

| 項目 | 内容 |
|---|---|
| パス | `/recipes/<slug>/edit` |
| ログイン | 要る。編集できる人と持ち主 |
| 骨組みと遷移 | [画面設計: 画面の一覧と遷移](../design/screens.md) の 3.3 と 3.8 |

## 対応する機能設計

| 文書 | この画面について決めていること |
|---|---|
| [機能設計: レシピ帳とレシピの編集](../design/recipe-edit.md) | 入力欄、並べ替えと削除、自動保存、同時に編集したときの動き、入力の検証 |
| [機能設計: 栄養計算](../design/nutrition.md) | 入力のたびに変わる栄養の値 |

## 見た目の試作

幅 1,100px のブラウザでの表示である。
枠の中は、押したりスクロールしたりできる。保存はされない。

### 持ち主。欄のエラーと、消した材料がある状態

広いときは、栄養の値を右の列に置き、スクロールしても見える位置に残す。
